Mandelbrot Emblem: Procedural 3D Terrain & Metallic Gold Generator

The Mandelbrot Emblem is an advanced Blender Python script that procedurally computes high-resolution Mandelbrot fractal heightmaps via NumPy, generates displaced 3D topography meshes, builds a custom multi-stop metallic gold shader network, and automatically annotates spatial coordinates down to 7 decimal places.

Features

  • NumPy-Accelerated Fractal Computation: Computes $z_{n+1} = z_n^2 + c$ across a $1280 imes 1280$ grid with up to 3,000 iterations for deep mathematical fidelity.
  • Non-Linear Height Shaping: Applies power-law scaling ($\gamma = 0.65$) to enhance topographic contrast between smooth escape basins and rugged fractal boundaries.
  • Automated Blender Pipeline:
    • Generates and packs procedural image textures directly into the Blender data block.
    • Creates a dedicated high-subdivision grid mesh with real-time displacement mapping (Z direction).
    • Smooths shading across geometry boundaries.
  • Custom Metallic Gold Material: Implements a fully configured Principled BSDF shader linked to a custom Color Ramp mapping deep antique bronze shadows ($ ext{RGB}: 0.35, 0.22, 0.04$), rich metallic gold midtones ($ ext{RGB}: 0.85, 0.65, 0.13$), and bright specular highlights ($ ext{RGB}: 1.0, 0.92, 0.55$).
  • Precision 3D Coordinate Markers: Automatically spawns a $6 imes 6$ grid of floating 3D text objects anchored to the terrain surface, formatting exact complex plane coordinates (X, Y) to 7 decimal places.

Installation & Usage

  1. Open Blender: Launch Blender (v3.0 or higher recommended) and open the Scripting workspace.
  2. Create New Text Block: Click New in the text editor header.
  3. Paste Script: Copy and paste the Python script into the text editor.
  4. Run Script: Click the Run Script (play icon) button or press Alt + P.

Customization

You can adjust the focal region by modifying the bounding box parameters in the script header:

xmin, xmax = -(0.7454297), -(0.7454287)  # Adjust X-axis boundaries
ymin, ymax = -(0.1130148), -(0.1130135)  # Adjust Y-axis boundaries
